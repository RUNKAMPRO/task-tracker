## 🖥️ OrbitOS: Das Web-Betriebssystem

OrbitSuite enthält ein komplettes, virtuelles Desktop-System direkt im Browser:

- **Echtes Fenstermanagement**: Fenster frei verschieben, in der Größe anpassen, minimieren, maximieren und stapeln.
- **Aesthetic macOS Controls**: Farbige Jewel-Window-Controls (Schließen, Minimieren, Vollbild) mit SVG-Mikro-Icons, Lichtreflexen und Hover-Animationen.
- **Doppelklick-Aktionen**: Schnelles Maximieren / Wiederherstellen durch Doppelklick auf die Fenstertitelleiste.
- **Taskleiste & Dock**: Aktive Fenster werden in der Taskleiste geführt; schnelles Umschalten wie auf einem echten Desktop.
- **Linux Superuser Shell (`sudo`)**: Integriertes Terminal mit Unix-Befehlen (`ls`, `cat`, `ps`, `top`, `sudo`, `help`) und In-Terminal Canvas Matrix Rain.
- **Dynamische Wallpaper**: Anpassbare Desktop-Hintergründe (Nebula, Deep Space, Cyberpunk, Minimalist Dark).

## 🚀 Die Haupt-Apps im Detail

### 📋 OrbitTask • Kanban & Aufgabenverwaltung
- **5 Kanban-Spalten**: *Backlog*, *Zu erledigen*, *In Bearbeitung*, *Prüfung*, *Erledigt*.
- **Drag & Drop**: Flüssiges Verschieben von Aufgabenkarten zwischen den Phasen.
- **Detaillierte Aufgaben**: Prioritäten (Niedrig, Mittel, Hoch, Kritisch), Fälligkeitsdaten mit Ampelwarnung, Tags und Checklisten-Subtasks.
- **SVG-Analytics**: Interaktive Diagramme zur Aufgabenverteilung und Erledigungsquote.

### 📝 OrbitNotes • Schnelle Notizen & Markdown
- **Markdown-Unterstützung**: Überschriften, Listen, Code-Blöcke und Textformatierung.
- **Farbkodierung**: Wähle Notizfarben für visuelle Unterscheidung nach Themen (Arbeit, Ideen, Privat).
- **Pinboard**: Wichtige Notizen direkt auf das Dashboard heften.

### ⏱️ OrbitFocus • Deep Work & Klangwelten
- **Pomodoro-Methodik**: Arbeitsintervalle (25 Min.) mit kurzen (5 Min.) und langen Pausen (15 Min.).
- **Integrierter Synthesizer (Web Audio API)**: Beruhigende Klangkulissen direkt im Browser generiert (Regenrauschen, Deep Space Drone, Brown Noise, Kaminfeuer) – komplett ohne externe Audio-Dateien.

### 🔄 OrbitHabits • Routine & Streak Tracker
- **7-Tage-Matrix**: Tägliche Gewohnheiten mit einem Klick abhaken.
- **Streaks & Disziplin**: Automatische Berechnung von aktuellen und längsten Erfolgsserien.

### 🛠️ OrbitTools • Schweizer Taschenmesser für Entwickler
- **JSON Studio**: Formatieren, Validieren und Minifizieren von JSON mit Syntax-Check.
- **RegEx Tester**: Reguläre Ausdrücke in Echtzeit gegen Teststrings mit Flags prüfen.
- **Crypto & Encoding**: Base64 Codierung/Dekodierung, MD5, SHA-256 und UUID v4 Generierung.

### 🧩 OrbitPlay • Tägliches Gehirntraining
- **6 vollwertige Spiele**:
  - 👑 **Queens**: Platziere Kronen ohne gegenseitige Bedrohung.
  - ☯️ **Tango**: Ausgewogenes Gitter aus Sonne und Mond.
  - 🔢 **Sudoku**: Klassisches 9x9 Zahlenrätsel mit Hinweissystem.
  - 🧗 **CrossClimb**: Wortketten-Rätsel mit Buchstabentausch.
  - 🎯 **Pinpoint**: Assoziations- und Kategoriensuche.
  - ⚡ **Zip**: Labyrinth- und Pfadverbindung.

## ⚡ Kernmerkmale & Technologie

- **Zero Dependencies**: Geschrieben in reinem, performantem Vanilla JavaScript (ES6+), modernem CSS3 und HTML5. Keine schweren Frameworks, kein Build-Step erforderlich.
- **Offline-First (PWA)**: Dank intelligenter Service-Worker-Architektur (`sw.js`) funktioniert OrbitSuite überall – auch ohne aktive Internetverbindung.
- **Optionale Cloud-Synchronisation**: Nahtlose PostgreSQL-Anbindung über [Supabase](https://supabase.com) mit Echtzeit-WebSockets. Daten werden zwischen PC, Tablet und Smartphone synchronisiert.
- **Maximale Privatsphäre**: Alle Daten bleiben standardmäßig lokal im Browser (`localStorage`). Im Cloud-Modus schützt PostgreSQL *Row Level Security (RLS)* deine Einträge.
- **Tastatur-Navigation**:
  - `Alt + 0` → Hub
  - `Alt + 1` → OrbitTask
  - `Alt + 2` → OrbitNotes
  - `Alt + 3` → OrbitFocus
  - `Alt + 4` → OrbitHabits
  - `Alt + 5` → OrbitTools
  - `Alt + 6` → OrbitPlay
  - `Alt + 7` → Folienwerk

## 💻 Schnellstart (Lokal)

1. Repository klonen oder herunterladen:
   ```bash
   git clone https://github.com/RUNKAMPRO/task-tracker.git
   cd task-tracker
   ```
2. Doppelklick auf **`Start_OrbitSuite.bat`** (startet den integrierten Webserver und öffnet den Browser auf `http://localhost:8080`).
3. Alternativ direkt mit beliebigem HTTP-Server starten:
   ```bash
   python -m http.server 8080
   ```
